# 📚 AppShelf sources

**Русский** · [English](README.md)

Каталог альтернативных источников Android-приложений — релизы на GitHub, каналы в Telegram, сайты проектов.
Им пользуется [AppShelf](https://github.com/Xtratter/appshelf) при настройке нового телефона.

AppShelf скачивает [`sources.json`](sources.json) целиком (не чаще раза в день), поэтому сведения о ваших
приложениях никуда не уходят. Ссылки, которые вы добавили в AppShelf сами, всегда стоят первыми; ссылки из
каталога — после них.

## Формат

```json
{
  "format": "AppShelf-sources",
  "version": 1,
  "apps": {
    "<имя пакета>": [
      { "url": "https://github.com/owner/repo", "label": "GitHub" },
      { "url": "https://t.me/channel", "label": "Telegram" }
    ]
  }
}
```

- Ключ — имя пакета приложения (AppShelf показывает его в карточке приложения и умеет копировать).
- `url` — любая ссылка `https://`: репозиторий GitHub (AppShelf скачивает и ставит APK из его последнего релиза — ссылка подходит для всех новых версий), репозиторий GitLab / Codeberg (открывается или добавляется в Obtainium),
  канал в Telegram, тема на форуме, сайт или прямая ссылка на `.apk`.
- `label` — необязательно: без неё AppShelf подпишет ссылку по сайту.

## Как добавлять ссылки

Добавьте ссылки в карточках приложений в AppShelf, затем **Сохранение и восстановление → Сохранить → Ссылки для каталога** выгрузит
готовый `sources.json` со всеми вашими ссылками — перенесите их сюда. Pull request'ы приветствуются.

## Свой каталог

Сделайте форк этого репозитория и укажите адрес своего `sources.json` в AppShelf (меню → Каталог ссылок).
Подойдёт любой адрес `https://`, который отдаёт этот формат.
